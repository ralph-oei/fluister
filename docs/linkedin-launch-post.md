Ik wilde m'n mail inspreken in plaats van typen. Elke tool die ik pakte: m'n stem gaat naar de cloud.

"Audio wordt verwerkt op onze servers." In kleine lettertjes, onderaan.

Da's je stem. Je klantnamen, je vergaderingen, je halve gedachten. Naar een server waar jij niks over te zeggen hebt.

Oké, ik bén een nerd. Dus ik bouwde m'n eigen dicteer-app. In m'n avonden. Fluister.

⌥Space ingedrukt houden. Praten. Loslaten. De tekst staat op je cursor. In je mail, in Slack, in Word, overal.

100% lokaal. Het model draait op de Neural Engine van je Mac. Trek je internet eruit en 't werkt gewoon door. Je stem verlaat je Mac niet. Punt.

Dicteren dat je stem naar een server stuurt, is een lek dat je zelf inspreekt. Lokaal betekent: er valt niks te lekken.

't Is gratis. Open source, dus je kan zelf in de code kijken wat 'ie doet. En vooral: wat 'ie niet doet. Voorlopig alleen voor de Mac.

Link in de comments.

Wat zou jij inspreken als je zeker wist dat 't je laptop niet verlaat?
