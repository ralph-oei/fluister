Je dicteert een berichtje, snel even. Handig. Alleen: bij de meeste dicteer-apps is dat de deal. Jij praat, de cloud luistert. Je stem, je woorden, staan een tel later op andermans server.

Daar had ik geen zin in. Dus bouwde ik er zelf een. Fluister.

Een gratis dicteer-app voor de Mac. ⌥Space vasthouden, praten, loslaten. De tekst verschijnt op je cursor, in elk venster waar je kan typen. En het belangrijkste: je stem verlaat je Mac niet. Alles draait lokaal, op je eigen machine. Geen cloud, geen account, geen telemetrie.

Open source, dus je hoeft me niet op m'n woord te geloven. Je kan 't zelf nakijken.

Je stem is van jou. Bij Fluister blijft dat zo.

Werk je op een Mac? Probeer 'm, kost niks. Link in de comments.

Waar zou jij 'm als eerste voor gebruiken?
